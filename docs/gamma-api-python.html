Polymarket Gamma API with Python

The Gamma API is Polymarket public catalog: every market, its outcomes, prices, volumes. No key required.

List active binary markets

import json, urllib.request

url = "https://gamma-api.polymarket.com/markets?active=true&closed=false&limit=100"
req = urllib.request.Request(url, headers={"User-Agent": "demo"})
data = json.loads(urllib.request.urlopen(req, timeout=30).read())

for m in data:
    prices = json.loads(m.get("outcomePrices") or "[]")
    if len(prices) == 2:
        print(m["question"][:60], prices)

Paginate correctly

Past the last page the API returns HTTP 422 - not an empty list. Catch it:

import urllib.error

def get_page(offset):
    url = f"https://gamma-api.polymarket.com/markets?limit=100&offset={offset}"
    try:
        req = urllib.request.Request(url, headers={"User-Agent": "demo"})
        return json.loads(urllib.request.urlopen(req, timeout=30).read())
    except urllib.error.HTTPError as e:
        if e.code == 422:
            return []
        raise

Fields that matter

  • outcomePrices, outcomes, clobTokenIds are JSON-encoded strings - double-decode them
  • negRisk marks sub-markets of a mutually-exclusive event group
  • volume24hr, liquidityNum for filtering tradeable markets
  • Gamma prices are midpoints, not executable bids - verify against the CLOB order book
