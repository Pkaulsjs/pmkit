Polymarket's Data APIs from Python

Polymarket has two public APIs and they answer different questions. Picking the wrong one is the most common mistake in Polymarket tooling:

APIAnswersAuth
Gamma (gamma-api.polymarket.com)What markets exist? What are their metadata, volumes, outcome prices?None
CLOB (clob.polymarket.com)What can I actually trade at right now? (real bids/asks)None (read-only)

Listing markets (Gamma)

import json, urllib.request

url = "https://gamma-api.polymarket.com/markets?limit=100&active=true&closed=false"
markets = json.loads(urllib.request.urlopen(url, timeout=30).read())

for m in markets[:3]:
    print(m["question"][:60], m.get("volume24hr"))

The midpoint trap

Gamma's outcomePrices are midpoints, not executable quotes. In a live scan of 2,100 binary markets we found zero cases where a midpoint-based "arb" survived contact with the actual CLOB book - apparent edges were phantom resting bids on dead markets or 4-share depth. Always validate against the book:

book = json.loads(urllib.request.urlopen(
    "https://clob.polymarket.com/book?token_id=" + token_id, timeout=30).read())
best_bid = max(book["bids"], key=lambda x: float(x["price"])) if book.get("bids") else None

Pagination gotcha

Both APIs paginate with offset, but return HTTP 422 once you walk past the last page instead of an empty list. Treat 422 as end-of-data or your scanner crashes mid-run.
