Polymarket WebSocket Streaming in Python

REST polling misses fast book changes. Polymarket streams market events over WebSocket at wss://ws-subscriptions-clob.polymarket.com/ws/market.

The subscription

After the handshake, send a masked text frame:

{"assets_ids": ["<token_id_1>", "<token_id_2>"], "type": "market"}

You then receive JSON events: book snapshots and price_change updates with timestamps.

Gotchas that cost us an afternoon

  • Client frames must be masked - sending raw JSON without RFC 6455 framing gets you a close frame: "bad MASK"
  • Idle sockets raise timeouts - treat them as normal, keep reading; only a close frame (opcode 0x8) ends the stream
  • Servers ping, you pong - reply to opcode 0x9 or the connection dies silently

Zero-dependency client

pmkit's stream.py implements the handshake, frame decoding, masking, and ping/pong on raw sockets - about 150 lines, no packages. Use it or read it to write your own.

from pmkit.stream import stream_market

stream_market(["<token_id>"], print, duration=60)
