pmkit

A clean Python toolkit for Polymarket market analysis - read-only, zero dependencies, no keys.

View on GitHub Quickstart

What you get

  • Market data clients - Gamma API (markets/events) and CLOB order books, best bid/ask, midpoints
  • Arbitrage scanners - binary YES+NO spread scan and negative-risk event scan with configurable buffer
  • Paper-trading ledger - simulate fills against live book prices without funds or keys
  • Typed config - dataclass-based settings with JSON load/save

Why pmkit

Most Polymarket scripts floating around are unmaintained gists with hidden key-handling risks. pmkit is read-only by design, stdlib-only, tested, and documented. Commercial license available for teams building trading infrastructure.

No financial advice. No profit guarantees. Prediction markets involve risk.
