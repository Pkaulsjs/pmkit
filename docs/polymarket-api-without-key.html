Polymarket API Without a Key

A surprising amount of Polymarket tooling needs zero credentials. Both public APIs serve anonymous traffic freely - no account, no wallet, no API key.

What works keyless

  • Market catalog - every active/resolved market with outcomes and volumes: GET gamma-api.polymarket.com/markets?active=true&closed=false&limit=100
  • Order books - full depth per outcome token: GET clob.polymarket.com/book?token_id=...
  • Live streaming - WebSocket book events at wss://ws-subscriptions-clob.polymarket.com/ws/market
  • Trade feed - recent trades across all markets: GET data-api.polymarket.com/trades?limit=100 (powers whale tracking)

What needs keys

Only order placement and user-specific data. Analysis, scanning, paper trading, monitoring - all keyless.

The one rule of keyless work

Be polite: modest request rates, cache what you can. The APIs are generous but not infinite; a scanner hammering them gets throttled and ruins it for everyone.

pmkit wraps all four surfaces stdlib-only - see the Gamma guide and CLOB guide.
