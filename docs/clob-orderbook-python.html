Polymarket CLOB Order Books in Python

Gamma gives you midpoints. The CLOB API gives you the actual resting orders. You need a token_id from Gamma clobTokenIds.

Fetch a book

import json, urllib.request

TOKEN = "21742633143463906290569050155826241533067279536803137953470645380173117809916"
url = "https://clob.polymarket.com/book?token_id=" + TOKEN
book = json.loads(urllib.request.urlopen(url, timeout=30).read())

bids, asks = book.get("bids") or [], book.get("asks") or []
if bids:
    best = max(bids, key=lambda x: float(x["price"]))
    print("best bid", best["price"], "size", best["size"])

Validate depth before trusting any arb

def executable_edge(no_token_ids):
    total = 0.0
    for t in no_token_ids:
        url = "https://clob.polymarket.com/book?token_id=" + t
        b = json.loads(urllib.request.urlopen(url, timeout=30).read())
        bids = b.get("bids") or []
        if not bids:
            return -1.0
        total += float(max(bids, key=lambda x: float(x["price"]))["price"])
    return total - 1.0

In an August 2026 live scan, 62 midpoint deviations collapsed to zero executable after this check - phantom bids on dead markets and 3-share depth. Always validate depth.
