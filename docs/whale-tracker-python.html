Tracking Polymarket Whales in Python

Large traders move thin prediction markets. Polymarket's public data API exposes recent trades without authentication:

import json, urllib.request

url = "https://data-api.polymarket.com/trades?limit=100"
trades = json.loads(urllib.request.urlopen(url, timeout=30).read())

for t in trades:
    usd = float(t.get("size", 0)) * float(t.get("price", 0))
    if usd >= 1000:
        print(t.get("proxyWallet", "")[:10], t.get("outcome"), t.get("price"), round(usd))

Caveats from live use

  • The default window is the last ~100 trades across all markets - whales are sparse there; poll continuously or filter by market
  • proxyWallet is a pseudonymous address, not a username - tracking an entity means tracking its addresses over time
  • Big prints are often hedges, not conviction - whale-following is a signal, not a strategy
